# 📈 StockBot — AI-Powered Equity Research Assistant

StockBot is an intelligent equity research assistant that uses **Large
Language Models (LLMs), Natural Language Processing (NLP), semantic search,
and vector embeddings** to simplify financial research.

The system allows users to provide financial news article URLs, process the
content, generate summaries, search the information semantically, and ask
questions about the retrieved financial content.

---

## 🚀 Features

- 🔗 Financial news article ingestion from URLs
- 📝 Automatic article summarization
- ✂️ Intelligent text chunking
- 🧠 HuggingFace-based text embeddings
- 🔎 Semantic similarity search using FAISS
- 💬 Context-aware question answering
- 📊 Financial information analysis
- ⚡ Fast information retrieval
- 🖥️ Interactive Streamlit interface
